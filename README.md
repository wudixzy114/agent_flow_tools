# Agent Flow Tools

面向大型 AI Agent 项目的递归任务分解、工作流编排、多 Agent 工具接入和自监督迭代系统。

当前版本是本地优先的 Web MVP，重点先打通四个基础闭环：

- 从项目说明沉淀为结构化任务节点。
- 用节点图查看任务拆分、依赖和状态。
- 在节点详情中补充问题答案、上下文和验收标准。
- 为任意节点生成 Agent 可读的任务单和服务接口任务单。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 当前能力

- `任务树`：展示项目、模块、原子任务节点。
- `可视化任务图`：以节点图展示递归拆解和工作流关系。
- `节点详情`：编辑标题、状态、摘要、上下文和补充问题答案。
- `新增子任务`：从当前节点继续拆分原子任务。
- `任务单生成`：生成包含全局目标、当前上下文、问题答案、工具说明和验收标准的 Markdown。
- `服务接口生成`：生成向上提供、向下依赖和集成说明。
- `Agent 适配器注册表`：先定义 Codex CLI、OpenCode、Copilot Agent 的统一接入抽象。
- `本地保存`：任务节点保存在浏览器 `localStorage`。

## 架构边界

```text
项目说明
  -> 需求追问
  -> 递归拆解
  -> 原子任务
  -> 工作流调度
  -> Agent 执行
  -> 报告回调
  -> 监督判断
  -> 后续任务或验收归档
```

第一版只做浏览器内的任务建模和任务单生成。真实 Agent 调用、进程监督、报告回调和多工作区并行执行会在后续阶段接入。

## 推荐后续路线

1. 数据持久化从 `localStorage` 升级为文件工作区，支持导入导出 `project.json`。
2. 增加任务原子性判定器，对节点自动给出拆分建议和追问清单。
3. 增加工作流模板编辑器，支持需求、实现、测试、审核、验收、性能对比节点。
4. 实现 CLI Agent 适配器：命令模板、工作目录、输入任务单、输出报告、退出码采集。
5. 定义 `agent-report.schema.json`，让监督 Agent 可以稳定读取报告。
6. 增加执行日志、失败重试、阻塞追问和审核返工机制。
